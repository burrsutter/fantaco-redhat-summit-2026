Architecture Overview

Traffic Flow
Audience member's phone │ ▼ Route 53: *.yougetaclaw.com → ALB │ ▼ AWS ALB (TLS termination, ACM cert) │ ▼ HAProxy on EC2 (:8080) │ ├─── Host: yougetaclaw.com ──────────────► Broker (:3000) │ (bare domain, first visit) │ │ ├─ Check cookie │ ├─ Assign route from pool │ ├─ Set cookie │ └─ 302 → claw-047.yougetaclaw.com │ ├─── Host: claw-047.yougetaclaw.com ───► HAProxy map lookup │ (after redirect) │ │ └─► OpenShift Route │ claw-28c43-ef0ea4.apps.ocp... │ │ │ └─► OpenClaw Gateway Pod │ (WebSocket, chat UI) │ └─── Host: yougetaclaw.com/status ───► Broker (:3000) (admin status board) └─ Read-only dashboard

Component Summary

Component What it does Where it runs
HAProxy Map-based host routing for claw-NNN URLs EC2 :8080
Broker (Node.js) Session assignment, cookie mgmt, status board EC2 :3000
SQLite DB Route pool + user assignments EC2 /var/lib/route-lb/broker.db
routes.csv (S3) Source of truth for route pool S3 bucket
audience-reset.sh Reset OpenClaw instances, generate new routes Admin laptop (oc CLI)

Request Flows

New User

  1. Arrives at yougetaclaw.com
  2. HAProxy forwards to Broker
  3. No cookie → pick available route
  4. Set cookie rlb_session=uuid
  5. 302 → claw-047.yougetaclaw.com
  6. HAProxy map → OpenShift Route
  7. OpenClaw Gateway UI loads

Returning User

  1. Arrives at yougetaclaw.com
  2. HAProxy forwards to Broker
  3. Cookie found → lookup assignment
  4. 302 → claw-047.yougetaclaw.com
  5. Same OpenClaw instance as before

All Slots Full

  1. Arrives at yougetaclaw.com
  2. HAProxy forwards to Broker
  3. No cookie, no available routes
  4. 503 — branded "all seats taken" page

Audience Reset

  1. Admin runs audience-reset.sh
  2. New OpenShift Routes created
  3. New routes.csv uploaded to S3
  4. HAProxy sync picks up new map
  5. Broker reloads pool, clears assignments
  6. Old cookies → treated as new users

Broker API Endpoints

Method Path Purpose
GET / Session assignment + redirect (or 503 "full")
GET /status Read-only status board HTML
GET /status/api JSON: route pool + assignment counts
POST /admin/reset Clear assignments, reload pool from routes.csv
POST /admin/release/:slot Release a single slot assignment
/admin/* endpoints are localhost-only or token-protected
